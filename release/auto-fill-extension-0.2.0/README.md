# 内容自动填写插件（0.2.0）

Chrome / Edge Manifest V3 扩展，无后端、无需构建。支持在普通网页中点选文本字段，把网站自己的「主题 / 正文」映射为统一的「标题 / 简介」，保存后再次一键填写。

## 安装或更新
1. Chrome/Edge 打开 `扩展程序`，开启“开发者模式”。
2. 选择“加载已解压的扩展程序”，选择本目录。
3. 点击扩展图标打开侧栏。

使用 Chrome / Edge 114 或更新版本。已安装的扩展点击「重新加载」，刷新目标网页，关闭旧侧栏并重新打开。日常使用无需 Node.js。

插件只填写文本并定位上传控件，不会点击最终发布，也不会保存账号密码。运行 `npm test` 验证规则引擎。

## 点选绑定与一键填写

1. 打开需要填写的网页，并展开其中的编辑表单。
2. 在「添加或重新绑定字段」下拉框中选择标题、简介等字段。下拉框只选择接下来要绑定的字段，不切换上方内容。
3. 选择「标题」，点击「绑定元素」。新站点会申请该站点访问权限，允许后继续。
4. 移到网页「主题」输入框上会显示蓝框，点击即可保存为「标题」的绑定。点选不会改变原文字；Esc 或侧栏「取消绑定」可取消，60 秒后也会退出。
5. 每成功绑定一个新字段，上方会新增一个独立的多行文本框。继续绑定简介、话题等，所有已绑定字段同时显示，可直接编辑。文本框默认一行，随换行、自动折行增高，删除文字后自动缩小；话题和标签仍按空白分隔。字段标题右侧的「修改」会直接进入该字段的网页点选模式，新元素选中后替换旧绑定，文本内容保留；取消点选则保留旧绑定。重新绑定同一字段不重复增加文本框。
6. 输入内容后点击「一键填写」，一次填写当前页面所有已绑定字段。非空内容会替换原内容，空内容会跳过。侧栏显示填写数量；失败时在对应文本框下显示红色提示，各字段错误同时保留。不会点击提交或发布。没有绑定字段时，填写按钮禁用。
7. 刷新或以后重新访问时无需重新绑定，文本框与草稿自动恢复。点击字段标题右侧的「删除」，或展开「网站规则」删除绑定；删除后移除该文本框但保留内容草稿，再次绑定会恢复内容。其他网站的绑定在「其他已保存规则」中管理。切换页面时仅显示该页面绑定的字段，相同统一字段共享草稿内容。

## 侧栏布局

默认显示一句说明、当前页面已绑定字段的多行文本框、字段选择、绑定与填写按钮，以及自动保存提示。没有绑定时显示简短引导，网站规则默认折叠。文本框初始高 36px，随内容自动增减高度，恢复草稿和调整侧栏宽度时也会重新计算；下拉框和主要按钮高 36px，字段右侧的小按钮高 24px。浅色界面、16px 内边距、12px 元素间距，支持键盘焦点与禁用状态，错误信息通过文字和红色边框同时提示。草稿约在停止输入 300ms 后保存，底部显示保存状态；一键填写前会立即保存。

## 匹配与边界

- 本地规则按协议、域名、端口、完整路径匹配，忽略查询参数及普通锚点；`#/editor`、`#!/editor` 形式的路由也纳入范围。同站不同路径互不影响，不提供通配符规则。通过查询参数区分用途的页面会共享规则，请只在相同用途的表单上使用。
- 侧栏只填写当前页面已绑定的字段，不会隐式查找未绑定的输入框。自定义映射使用原始内容，话题/标签数组以空格连接，不套用平台截断规则。
- 支持普通文本 input、textarea、主文档中的普通 contenteditable。文件上传、密码、下拉选择、iframe、Shadow DOM 和特殊富文本/话题候选组件暂不支持通用绑定，需要专门适配。浏览器内部页和扩展商店等受保护页面无法操作。
- 优先使用稳定属性；无唯一属性时用结构路径并提示。找不到元素会等待最多 3 秒；重复匹配、已知属性/标签变化、隐藏、禁用、超长时会给出提示。无法保证所有网站改版都能检测，特别是结构定位；请检查填写结果，必要时重新绑定。
- 触发 input / change / blur 后检查 DOM 是否保留写入值；该检查不代表网站业务校验通过或服务器已保存。
- 授权按站点申请；内容及映射存于 `chrome.storage.local`，不上传云端，不保存密码。规则表保存定位属性和标签，不保存网页表单值。卸载扩展会删除这些本地数据。

## 本地测试

快速规则及清单检查：`npm test`。

交互测试页：`npm run demo`，访问 `http://127.0.0.1:4173/publish`。该页面提供「主题」「正文」「关键词」以及模拟发布计数，使用上面的绑定步骤验证；刷新后再次填写，发布计数应始终为 0。`/other` 可用于检查不同路径的隔离。

自动化浏览器回归（Node.js 20 或更新版本）：

```sh
npm ci
npx playwright install chromium
npm run test:e2e
```

测试在独立临时浏览器配置中加载真实扩展，使用拦截的模拟网页，不访问或操作媒体账号。覆盖点选、本地保存、刷新恢复、填值和事件、规则隔离、删除、取消、受限字段、超长内容、异步渲染、定位失效等。首次站点授权弹窗和各真实网站组件仍需人工验证。

Windows 如下载的 Chromium 无法启动，可以指定本机 Edge（PowerShell）：

```powershell
$env:TEST_CHROMIUM_PATH = 'C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe'
npm run test:e2e
```
