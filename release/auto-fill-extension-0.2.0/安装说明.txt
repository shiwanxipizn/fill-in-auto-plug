内容自动填写插件 0.2.0 — 安装说明

支持 Windows / macOS 的 Chrome、Edge 114 及以上版本；本包不能直接安装到 Safari。
无需 Node.js、npm，也不需要运行任何安装脚本。

首次安装：
1. 将 ZIP 解压到一个固定目录，不要直接在压缩包里操作。
2. Chrome 打开 chrome://extensions；Edge 打开 edge://extensions。
3. 开启“开发者模式”，选择“加载已解压的扩展程序”。
4. 选择解压后包含 manifest.json 的目录。
5. 打开目标网页，点击扩展图标，选择字段并绑定网页元素。

已有版本升级（保留现有规则与草稿）：
请勿卸载原扩展。把本包的 manifest.json 和 src 目录覆盖到原来加载的插件目录，
在扩展管理页点击“重新加载”，刷新网页，关闭并重新打开侧栏。
例如原目录为 D:\demo\publish-auto，则继续使用该目录。
改用另一目录重新加载可能生成不同扩展 ID，不会自动带上原有本地数据。

运行文件：manifest.json 和 src 目录。README.md 与本说明用于阅读。
不要移动或删除正在被浏览器加载的运行目录。
ZIP 是供解压加载的分发包，不是双击安装程序或可直接拖入安装的商店包。
